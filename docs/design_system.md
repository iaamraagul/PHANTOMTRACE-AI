# Design System

PHANTOMTRACE AI uses a restrained security-research workstation direction, not a marketing landing page.

Palette:

- Ink: `#111211`
- Charcoal: `#1a1b18`
- Warm surface: `#24231e`
- Parchment: `#d8cfbe`
- Muted olive: `#6b705c`
- Copper: `#b5663f`
- Electric amber: `#e9a23b`
- Danger: `#d95c4a`
- Success: `#8fa36a`

Typography:

- Interface: Manrope
- Technical labels: DM Mono
- Editorial headings: Instrument Serif

Rules:

- Use 3D only to represent scan risk, feature activity, or history.
- Provide a 2D accessible equivalent for every WebGL-only view.
- Avoid purple-blue gradients, generic cyber grids, excessive glow, repeated glass cards, and fake analytics.
- Prefer asymmetric layouts, tactile borders, restrained color, and dense but readable information.
- Respect `prefers-reduced-motion`.

Anti-template checklist:

1. Does this look like a template?
2. Is it overly symmetrical?
3. Does it use a generic gradient?
4. Are there too many cards?
5. Is the 3D element meaningful?
6. Is there unnecessary glow?
7. Is visual hierarchy clear?
